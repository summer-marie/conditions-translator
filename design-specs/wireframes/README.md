# Wireframes

Final wireframe exports for the Conditions Translator MVP.

## Subfolders

- **`exports/`** — final visual wireframes (Figma exports, PNG mockups, SVG, and other design-tool outputs)

## Adding Wireframes

1. Place final wireframe exports in `exports/`
2. Name files descriptively: `{feature}-{context}.{ext}` (e.g., `mobile-chat.png`, `browser-dashboard.png`)
3. Update `docs/Wireframe_Implementation.md` with links to the new assets
